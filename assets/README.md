# Assets Folder

This folder contains static assets for the portfolio.

## Profile Picture

Please add your profile picture as `profile-pic.jpg` in this folder. The recommended size is 400x400 pixels or larger (square aspect ratio) for best quality.

If you don't have a profile picture yet, you can:
1. Use a placeholder image service temporarily
2. Add your actual profile picture later

The profile picture will be displayed in the hero section with a circular frame and gradient border.
